# Small Business Landing Template

This template is intentionally content-first and modular.

## Quick text replacement

Update `content.ts` to replace all placeholder text, links, and image URLs.

## Structure

- `SmallBusinessLandingTemplate.tsx`: page composition
- `content.ts`: central dummy/default copy
- `types.ts`: strict content shape for AI-safe edits
- `components/*`: one file per section

## Sections

- Hero
- About
- Services
- Gallery
- Contact
- CTA
