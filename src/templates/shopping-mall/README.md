# Shopping Mall Template Page

Reusable ecommerce page intended for template resale workflows.

## Includes

- Simple hero section with configurable copy and CTA
- Product grid via `ProductList`
- Local `mockProducts` import for quick preview scaffolding

## Customization flow

1. Replace `mockProducts` with your own data source.
2. Edit hero props (`heroHeadline`, `heroSupportingText`, CTA fields).
3. Re-theme `shoppingMallTemplate.css` for brand-specific variants.
